# Drosophilam_multiallelic

\textbf{1. Purpose}
This workflow processes pooled Drosophila melanogaster sequencing data across 15 sampling time points. It calls variants/alleles, applies alternative filtering and conversion strategies, creates allele-frequency trajectories, estimates fitness matrices, evaluates heterozygote advantage, annotates multiallelic loci, and performs coverage- and resistance-gene-focused analyses.
